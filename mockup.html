QUESTÃO 04 DE 20 // OWASP API SECURITY Peso: 1.5 Pontos
Em uma arquitetura moderna de microsserviços, qual mecanismo é estritamente necessário para garantir que o cliente original autenticado no API Gateway não tenha sua identidade forjada durante a comunicação leste-oeste (service-to-service)?
A) Apenas assinatura HMAC no cabeçalho HTTP da requisição inicial do navegador.
B) Propagação de tokens criptográficos assinados (JWT / SAML) associados a mTLS (Mutual TLS) entre os nós da service mesh.
C) Remoção de toda autenticação interna para reduzir a latência de rede entre clusters.
D) Utilização de cookies de sessão com flag HttpOnly e SameSite=Lax nos microsserviços internos.
✔ Resposta Correta (Gabarito B): O mTLS garante a identidade da máquina/contêiner de origem através de certificados X.509, enquanto o token propagado (JWT) transporta o contexto do usuário autenticado no perímetro, estabelecendo o modelo Zero Trust.
